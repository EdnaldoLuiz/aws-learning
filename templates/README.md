# Templates

Use o modelo de serviço para uma referência conceitual e o de laboratório para passos com resultado verificável e limpeza. Substitua instruções por conteúdo real, informe estado e origem e inclua a página no índice da categoria. Uma pasta nova precisa de README com finalidade, conteúdo, ponto de entrada e retorno; uma nota simples pode ser arquivo. Não crie páginas vazias para cumprir uma árvore.

| Material | Como usar |
| --- | --- |
| [Serviço](servico.md) | Problema, decisão, conceitos, segurança/custos, perguntas e fontes |
| [Laboratório](laboratorio.md) | Autorização, custos, passos, verificação, diagnóstico e limpeza |
