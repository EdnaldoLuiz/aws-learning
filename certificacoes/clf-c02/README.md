# AWS Certified Cloud Practitioner — CLF-C02

Esta trilha organiza estudo para reconhecer conceitos, segurança, serviços e custos. Comece pelo mapa abaixo e pelas anotações específicas; use revisão e registro de erros para orientar sessões futuras. A existência das páginas não comprova domínio ou aprovação.

## Guia oficial e limite de atualidade

- [Página oficial](https://aws.amazon.com/certification/certified-cloud-practitioner/)
- Confira **código, edição do guia, domínios, pesos, formato, idiomas e critérios vigentes** na página oficial antes de planejar ou agendar o exame.
- `CLF-C02` é o código do acervo anterior. Sua vigência e os guias não puderam ser confirmados online em 2026-10-30: fontes AWS bloquearam acesso HTTP 403. Esta página não apresenta cobertura integral dos domínios ou pesos oficiais.
