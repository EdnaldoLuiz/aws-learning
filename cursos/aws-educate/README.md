# AWS Educate

Os módulos abaixo registram notas do Educate. Comece por Cloud 101 e depois escolha Compute, Storage, Security ou Cloud Operations conforme a etapa de estudo. As introduções de Cloud 101 e Storage vieram do TXT triado; capítulos gerais foram consolidados nas referências principais. A presença de material ou imagem de badge não registra conclusão.

| Material | Como usar |
| --- | --- |
| [Cloud 101](cloud-101.md) | Definir nuvem, comparar modelos/serviços, entender infraestrutura global e orientar prática futura de serviços essenciais |
| [Getting Started with Storage](storage.md) | Tipos de armazenamento, S3, buckets, upload, segurança e contexto de site estático; referência de classes consolidada em S3 |
| [Getting Started with Compute](compute.md) | Hardware, software, processamento e escolha inicial de recursos; a introdução antiga de Compute no TXT estava vazia |
| [Cloud Operations](cloud-operations.md) | Operação, ferramentas, custos, governança e observações do módulo |
| [Security](security.md) | Rascunho incompleto: retomar as quatro seções, sem presumir curso concluído |
